# Changelog

## 1.0.0

### Added

- Define Behavior clarifies observable outcomes with the user and hands agreed scenarios to Sociable TDD.
- Sociable TDD guides features, bug fixes, and behavior-preserving refactors through fast tests at the consumer interface. Its references cover test selection, doubles, exploratory probes, and optional mutation checks.
- The Swift photo demo compares classic and mockist tests through the same refactor. Both suites run in a dedicated test host and use controlled responses.
- The README documents installation with the Skills CLI for Codex and Claude Code, manual installation, and prompts for both skills.
- The repository and both installable skill folders include the Apache 2.0 license.
